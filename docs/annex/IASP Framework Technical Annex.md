# IASP Framework Technical Annex

This annex bundles the Informative Authoring Semantics Profile (IASP) framework
documentation into a single distributable document. IASP is the semantic
vocabulary and Pandoc-based build pipeline developed for *The Struggle Against
Dehumanization*—though the framework itself is reusable for any long-form
nonfiction project.

This annex is generated from the documentation in the iasp-build repository.

**Note on internal links**: Some included documents contain cross-references
intended for browsing the iasp-build documentation on GitHub. Use the table
of contents below to navigate this edition.
:::
